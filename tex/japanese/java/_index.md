## JavaでZIPアーカイブを作成する方法は？

`ZipArchive` は ZIP ファイルの作成と操作を行います。バンドルしたいファイルをロードし、`ZipArchive` オブジェクトをインスタンス化し、各エントリを追加して `save("archive.zip")` を呼び出します。この 2 段階のアプローチにより、メモリ上で準拠した ZIP を構築し、ディスクに書き込むことができます。数十 MB の LaTeX リソースを含むアーカイブでも、メモリ使用量は 50 MB 未満です。API は UTF‑8 ファイル名を扱い、ディレクトリ構造を保持します。

## JavaでZIPファイルを抽出する方法は？

ソースアーカイブを指す `ZipArchive` インスタンスを作成し、`extractAll("targetFolder")` を呼び出します。抽出はストリーミングモードで実行され、メモリに保持するバッファは小さく抑えられるため、1 GB を超えるアーカイブでも低スペックサーバーで展開可能です。エラーは例外で報告されるため、リトライロジックの実装が容易です。

## TeX ドキュメントを PDF として保存する方法は？

`TeXDocument` は Aspose.TeX のコアクラスで、LaTeX ソースファイルをロードします。ロード後、`save("output.pdf", SaveFormat.Pdf)` のように希望のフォーマットで `save` メソッドを呼び出します。この 2 行のシーケンスで **how to convert latex** の全工程が完了し、パッケージ、フォント、画像を自動的に解決して元のレイアウトに一致する PDF を生成します。大規模ドキュメントの場合はストリーミングモードを有効にし、メモリ使用量を 100 MB 未満に抑えます。

## よくある質問

**Q: 一時ファイルを作成せずに ZIP アーカイブを作成できますか？**  
A: はい、Aspose.TeX の `ZipArchive` は完全にメモリ上で動作し、アーカイブを直接レスポンスやクラウドストレージへストリームできます。

**Q: Java でパスワード保護された ZIP ファイルを抽出するには？**  
A: `ZipArchive` コンストラクタまたは `extractAll` メソッドにパスワードを渡すだけで、ライブラリがリアルタイムでエントリを復号します。

**Q: フォントを保持したまま TeX ドキュメントを PDF に保存できますか？**  
A: もちろんです。`save` メソッドは参照されているすべてのフォントを埋め込み、元のレイアウトと完全に一致する PDF を生成します。

**Q: Aspose.TeX が処理できる ZIP アーカイブの最大サイズは？**  
A: ストリーミングモードを使用すれば 2 GB を超えるアーカイブも処理可能で、必要なのは一時バッファ用のディスク容量だけです。

**Q: 全体を解凍せずに特定のファイルだけを抽出できますか？**  
A: はい、`extractEntry("path/to/file.tex")` を呼び出すことで単一エントリを取得でき、選択的処理に便利です。
