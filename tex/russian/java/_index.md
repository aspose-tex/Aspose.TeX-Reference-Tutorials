## Как создать zip‑архив в Java?

`ZipArchive` создает и управляет ZIP‑файлами. Загрузите файлы, которые хотите упаковать, создайте объект `ZipArchive`, добавьте каждую запись и вызовите `save("archive.zip")`. Этот двухшаговый подход создает корректный ZIP в памяти и записывает его на диск, используя менее 50 МБ ОЗУ даже для архивов, содержащих десятки мегабайт ресурсов LaTeX. API обрабатывает имена файлов в UTF‑8 и сохраняет структуру каталогов.

## Как извлечь zip‑файлы в Java?

Создайте экземпляр `ZipArchive`, указывающий на исходный архив, затем вызовите `extractAll("targetFolder")`. Извлечение работает в режиме потоковой передачи, что означает, что в памяти хранится лишь небольшой буфер, позволяя распаковывать архивы размером более 1 ГБ на скромных серверах. Ошибки сообщаются через исключения, что упрощает добавление логики повторных попыток.

## Как сохранить документ TeX в PDF?

`TeXDocument` — основной класс Aspose.TeX, который загружает исходный файл LaTeX. После загрузки вызовите его метод `save` с нужным форматом, например `save("output.pdf", SaveFormat.Pdf)`. Эта простая двухстрочная последовательность выполняет полную операцию **how to convert latex**, автоматически разрешая пакеты, шрифты и изображения для создания PDF, соответствующего оригинальному макету. Для больших документов включите режим потоковой передачи, чтобы потребление памяти оставалось ниже 100 МБ.

## Часто задаваемые вопросы

**Q: Могу ли я создать zip‑архив без записи временных файлов?**  
A: Да, `ZipArchive` из Aspose.TeX работает полностью в памяти, позволяя передавать архив напрямую в ответ или облачное хранилище.

**Q: Как извлечь zip‑файл, защищённый паролем, в Java?**  
A: Передайте пароль в конструктор `ZipArchive` или в метод `extractAll`; библиотека будет расшифровывать записи на лету.

**Q: Можно ли сохранить документ TeX в PDF, сохранив оригинальные шрифты?**  
A: Абсолютно — метод `save` встраивает все используемые шрифты, гарантируя, что PDF точно соответствует исходному макету.

**Q: Каков максимальный размер zip‑архива, который может обрабатывать Aspose.TeX?**  
A: Библиотека обрабатывает архивы более 2 ГБ в режиме потоковой передачи, ограничиваясь только доступным дисковым пространством для временных буферов.

**Q: Поддерживает ли Aspose.TeX извлечение конкретных файлов из zip‑архива без полной распаковки?**  
A: Да, вы можете вызвать `extractEntry("path/to/file.tex")`, чтобы получить отдельную запись, что полезно для выборочной обработки.
